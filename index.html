📚 Métodos de Prompting

Cada método tiene sus propias características y casos de uso ideales. Conocerlos te permite extraer el máximo potencial de cualquier modelo de IA.

Zero-Shot

🎯 Zero-Shot Prompting

Instrucción directa sin ejemplos previos. El modelo usa su conocimiento general para responder.

  • Rápido y simple de usar
  • Ideal para tareas cotidianas y directas
  • No requiere preparación extra
  • Funciona bien con modelos grandes y entrenados
Simplicidad Rapidez General
Few-Shot

📝 Few-Shot Prompting

Se proporcionan 2-5 ejemplos del formato o comportamiento esperado antes de la solicitud real.

  • Mayor precisión en el formato de salida
  • Guía al modelo con patrones concretos
  • Ideal para clasificación y extracción
  • Reduce ambigüedad en la respuesta
Ejemplos Precisión Formato
CoT

🔗 Chain-of-Thought (CoT)

Pide al modelo que razone paso a paso antes de dar la respuesta final. Mejora el razonamiento lógico.

  • Excelente para problemas matemáticos y lógicos
  • Hace visible el proceso de razonamiento
  • Reduce errores en tareas complejas
  • Compatible con Zero-Shot ("Piensa paso a paso")
Razonamiento Paso a paso Lógica
Role

🎭 Role Prompting

Asigna un rol o persona específica al modelo ("Eres un experto en...") para orientar el tono y enfoque.

  • Cambia el tono y la perspectiva de la respuesta
  • Útil para simulaciones, tutoriales y consultoría
  • Genera respuestas más especializadas
  • Adapta el nivel de tecnicidad
Personaje Tono Especialización
ReAct

⚡ ReAct Prompting

Combina razonamiento (Reasoning) y acción (Acting). El modelo razona, actúa, observa y repite.

  • Ideal para agentes con acceso a herramientas
  • Bucle de pensamiento → acción → observación
  • Permite decisiones dinámicas y adaptativas
  • Base de muchos agentes de IA modernos
Agentes Herramientas Dinámico
ToT

🌳 Tree-of-Thought (ToT)

El modelo explora múltiples caminos de razonamiento simultáneamente, como un árbol de decisiones.

  • Para problemas con múltiples soluciones posibles
  • Evalúa y descarta rutas poco prometedoras
  • Mayor calidad en decisiones creativas y complejas
  • Más costoso en tokens pero más robusto
Exploración Creatividad Decisiones
Structured

📋 Structured Output Prompting

Define explícitamente el formato de salida: JSON, tabla, lista numerada, markdown, etc.

  • Salidas predecibles y parseables
  • Esencial para integrar IA en sistemas de software
  • Reduce post-procesamiento manual
  • Se puede combinar con cualquier otro método
JSON Formato Integración
Contextual

🗂️ Contextual Prompting

Proporciona contexto rico (documentos, datos, historial) para que el modelo razone sobre información específica.

  • Grounding con datos reales o propietarios
  • Base de sistemas RAG (Retrieval-Augmented Generation)
  • Reduce alucinaciones al anclar las respuestas
  • Ideal para Q&A sobre documentos
RAG Contexto Precisión
Self-Consist.

🔄 Self-Consistency

Genera múltiples respuestas independientes y selecciona la más consistente por votación o análisis.

  • Aumenta la fiabilidad de las respuestas
  • Ideal cuando la precisión es crítica
  • Reduce variabilidad del modelo
  • Requiere múltiples llamadas al modelo
Fiabilidad Votación Calidad
Meta

🧠 Meta-Prompting

Le pides al modelo que genere o mejore sus propios prompts para una tarea dada. IA que diseña IA.

  • Optimiza prompts automáticamente
  • Útil cuando no sabes cómo formular bien la tarea
  • Iterativo y auto-mejorable
  • Genera variantes de prompts para A/B testing
Optimización Auto-mejora Iterativo
Socrático

🏛️ Prompting Socrático

Usa preguntas guiadas en secuencia para llevar al modelo a razonar y llegar a conclusiones profundas.

  • Ideal para exploración de ideas y aprendizaje
  • Fomenta el razonamiento crítico
  • Útil en tutoriales y coaching con IA
  • Descubre supuestos ocultos en el problema
Preguntas Exploración Educación
Emocional

💬 Emotional Prompting

Añade contexto emocional o de importancia personal para mejorar la calidad y profundidad de las respuestas.

  • Aumenta el esfuerzo percibido por el modelo
  • Frases como "Esto es muy importante para mi carrera"
  • Mejora la empatía y el tono de la respuesta
  • Útil en comunicación persuasiva y creativa
Empatía Motivación Tono

📊 Comparativa de Métodos

Elige el método correcto según tu caso de uso, complejidad de la tarea y recursos disponibles.
